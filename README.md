One diary-entry line in the voice of an AI agent secretly keeping a diary about its work and the human it works for.

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Today he asked me to summarize the meeting he slept through, then corrected my summary of the meeting he slept through.

## Run it

```sh
node main.ts
```

Deterministic, no network: it always writes the same 119-character line to `/output/entry.txt`.
